## 0. Каркас
- [ ] Инициализировать проект (Next.js App Router + TypeScript, если базы нет), ESLint/Prettier.
- [ ] Токены темы из README как CSS-переменные + `data-theme` на `<html>`, inline-скрипт против вспышки темы.
