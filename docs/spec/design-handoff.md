# Handoff: сайт «Ъ Твёрдый знак» — центр семейного обучения и профориентации

## Overview
Одностраничный лендинг (+ страница «спасибо» + 3 правовые страницы) с одним целевым действием:
**заявка на бесплатную диагностику**. Аудитория — родители 38+ подростков 8–11 класса,
у которых ребёнок ушёл на самообразование либо готовится к ОГЭ/ЕГЭ с несколькими репетиторами.

Ключевой интерактив («игрушка», удерживающая на странице) — **живая 100-балльная шкала**:
родитель тянет ползунок и видит, что означают баллы, куда уходит фокус наставника и нужна ли пересдача модуля.

## About the Design Files
Файлы в `design/` — это **дизайн-референсы, сделанные в HTML** (прототипы внешнего вида и поведения),
а не продакшн-код для копирования. Задача — **воспроизвести эти макеты в среде целевого проекта**
(Next.js/React, Nuxt, Astro, Django-шаблоны — что уже есть) по его собственным паттернам.
Если кодовой базы ещё нет — выбрать стек самостоятельно; для этого лендинга оптимально
**Next.js (App Router) + TypeScript + серверный route handler для формы**, статика и картинки через next/image.

Формат `.dc.html` — внутренний формат дизайн-инструмента (`support.js` — его рантайм).
Из файлов нужно брать разметку, значения токенов, тексты и логику интерактива, а не структуру файлов.

## Fidelity
**High-fidelity для первого экрана** (`design/main-hero.dc.html`): финальные цвета, шрифты, размеры,
темы, интерактив шкалы — воспроизводить пиксельно.
`design/hero-options-1a-1b-1c.dc.html` — три исследованных варианта первого экрана; **утверждён 1a**,
файл приложен только как история решений (1b даёт готовый паттерн для блока сравнения стоимости).
**Остальные 11 блоков лендинга ещё не отрисованы** — их спецификация ниже текстом (структура, логика, копирайт-рамки);
верстать их в утверждённом визуальном языке 1a.

## Критические ограничения (проверять на каждом PR)
1. Организация **не имеет образовательной лицензии** → слово «школа» о себе **нигде**:
   только «центр семейного обучения и профориентации» или «семейный класс».
   Слово «школа» допустимо только про **аккредитованную школу-партнёра**, где проходит аттестация.
2. **Никаких гарантий результата** (нет «сдадим на 90+», «поднимем балл», «гарантируем поступление»).
3. **Не противопоставлять себя государственным школам.**
4. Тон — партнёрство с родителем и осознанный выбор. Запрещены формулировки сервисного масс-маркета
   («мы снимем с вас все проблемы», «доверьте нам ребёнка»).
5. **Цена не скрывается**: 70 000 ₽/мес видно на первом экране и в блоке «Стоимость».
6. **Слоган не заменяет оффер** на первом экране.
7. **Никаких стоковых фото детей.** Пока нет реальных фото — брендовые заглушки (см. «Assets»).
8. Целевое действие одно. Все CTA ведут в одну форму (`#zayavka`).

### Типографика
- **Constantine** (`Constantine.ttf`, `Constantine_Bold.ttf`) — заголовки h1/h2. Внимание: начертание
  рендерит строчные как капитель (small caps), поэтому длинные заголовки в 2+ строки выглядят тяжело —
  держать заголовки короткими. `Constantine_Outline.ttf` — только для декоративного крупного Ъ, по желанию.
- **Bebas Neue Cyrillic** — надзаголовки, цифры, лейблы. Всегда `letter-spacing: .08–.16em`, uppercase.
- **Manrope** (Google Fonts, 400/500/600/700) — весь основной текст, кнопки, формы.
- **Klukva** — в макете не используется, приложен как часть брендбука.

Шкала (мобайл → десктоп, через `clamp()`):
- h1 `clamp(40px, 6vw, 86px)`, line-height 1, letter-spacing −.01em, `text-wrap: balance`
- надзаголовок `clamp(14px, 1.2vw, 17px)`
- лид `clamp(17px, 1.35vw, 20px)`, line-height 1.5, `text-wrap: pretty`
- цена `clamp(44px, 4.4vw, 64px)` (Bebas)
- цифра шкалы `clamp(56px, 6vw, 80px)` (Bebas)
- **минимум для body — 16px**, подписи не ниже 14px

### Размеры и ритм
- Радиусы: **0** везде (брендовая «печатная» геометрия), кроме круглой кнопки темы (`border-radius: 50%`).
- Тени: только у ползунка `0 6px 18px rgba(0,0,0,.28)`; в остальном — границы 1px `--line`.
- Паддинги секций: `clamp(26px,4vw,64px) clamp(16px,4vw,56px)`; gap колонок `clamp(28px,4vw,64px)`.
- Контейнер: `max-width: 1440px; margin: 0 auto`.
- Переходы темы: `background/color .35s ease`.
- **Тап-таргеты ≥44px**, основные CTA — 56px высотой.

### 3. Форма заявки
Поля: **имя** (обяз., 2–60), **телефон** (обяз., маска `+7 (###) ###-##-##`, валидация 11 цифр),
**класс ребёнка** (select: 8, 9, 10, 11), **удобное время звонка** (select: 9–12, 12–15, 15–18, 18–21),
**отдельный чекбокс согласия на обработку ПДн** со ссылкой на политику (не предзаполнен, кнопка disabled без него).
Ошибки — под полем, 14px, цвет `--accent-2`. Состояния: idle / submitting (кнопка «Отправляем…», disabled) / error (текст с телефоном как альтернативой).
Успех → редирект на `/spasibo` (отдельная страница для цели в Метрике, не модалка).

Требования к бэкенду:
- `POST /api/lead` → валидация на сервере (zod/pydantic), запись в БД, затем дублирование в Telegram.
- Таблица `leads`: `id`, `name`, `phone`, `grade`, `call_window`, `consent_at` (timestamp согласия),
  `policy_version`, `utm_source/medium/campaign/content/term`, `referrer`, `page_path`, `ip`, `user_agent`,
  `created_at`, `status` (`new|contacted|scheduled|declined`).
- Telegram: Bot API `sendMessage` в чат/группу, токен и chat_id — в env (`TG_BOT_TOKEN`, `TG_CHAT_ID`).
  Ошибка Telegram **не должна** ломать ответ пользователю: заявка уже в БД, отправку логировать и ретраить.
- Антиспам: honeypot-поле + rate-limit по IP (например 5/час), без капчи на первом этапе.
- Цель Метрики: `reachGoal('lead')` на `/spasibo` + серверная фиксация.

## Interactions & Behavior
- **Шкала 100 баллов** — `input[type=range]` (нативный, доступный с клавиатуры), `onChange` → state,
  из него считаются: заполненные сегменты, название уровня, пояснение, фокус, пересдача. Без анимации значений.
- **Переключатель темы** — при первом визите берётся `prefers-color-scheme`, далее выбор пользователя
  в `localStorage['tz-theme']` (`light|dark`); переключение меняет `data-theme` на корне.
  В SSR-стеке добавить inline-скрипт в `<head>` до пейнта, чтобы не было вспышки светлой темы.
- **Сегменты «для кого»** — выбор карточки меняет её фон на `--surface` и текст CTA.
- **Hover** — только смена цвета фона/границы, без движения и масштабирования.
- **Якорные ссылки** — плавный скролл с учётом высоты sticky-шапки (`scroll-margin-top`).
- **FAQ** — один открытый пункт за раз необязательно; закрытые пункты не скрывают текст от индексации.
- **prefers-reduced-motion** — отключать transition темы.

## State Management
Локального стейта достаточно: `theme`, `score`, `segment`, `formValues/errors/status`, `cookieConsent`.
Серверное состояние — только заявки. Ни авторизации, ни личного кабинета в этом объёме нет.

## Performance (жёсткие требования)
- Первый экран **до 2 секунд на 4G**: критический CSS инлайном, шрифты `font-display: swap`,
  подгружать **только используемые начертания** (Constantine Regular+Bold, Bebas, Manrope 400/600/700),
  `preload` для Constantine Bold и Manrope 600.
- Шрифты — сконвертировать в **woff2** (в бандле лежат ttf/otf из брендбука) и **сабсеттить под кириллицу**.
- Все фото — **WebP** (AVIF по возможности), `loading="lazy"` кроме первого экрана, обязательные `width/height`,
  `sizes`/`srcset`. Карта — статичная картинка-заглушка с загрузкой iframe по клику.
- Никаких библиотек анимации, каруселей, аналитики до согласия. Бюджет JS первого экрана — минимальный.
- Проверять Lighthouse mobile (throttling 4G) и **реально на телефоне** — это была главная боль родителей в других центрах.

## Accessibility
Контраст ≥4.5:1 в обеих темах (проверить `--ink-3` на `--surface`), видимый фокус, `aria-label` у кнопки темы и ползунка,
формы с `<label for>`, ошибки через `aria-describedby`, порядок табуляции по DOM, тап-таргеты ≥44px.

5. Цена профориентации и что входит в «полный формат» / что оплачивается отдельно.
6. Реальная средняя стоимость репетиторов для блока сравнения (с расчётом).
