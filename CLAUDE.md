# Твёрдый знак

Семейный класс и профориентация для подростков 8–11 классов, Красноярск.
Публичный сайт — https://tverdyy-znak.ru

## Выкат

**В конце каждого ответа, где что-то запушено, приводить команду выката
целиком.** Проектов у владельца много, команды путаются; «выкати как
обычно» — не подсказка, а лишний поиск по переписке.

```
ssh tz@85.198.66.41 tz-deploy
```

Ветка по умолчанию — та, что уже выкачена. Другую передают аргументом:
`tz-deploy main`. Локальная копия не нужна — команду можно выполнить
и с телефона. Подробности: `docs/DEPLOY-WINDOWS.md`.

Сервер сам забирает ветку из GitHub, пересобирает контейнеры, применяет
миграции, собирает статику, обновляет справочники и фотографии,
перечитывает nginx и дожидается `healthz`.

## Что нельзя нарушать

- У центра **нет образовательной лицензии**: слово «школа» о себе не
  употребляется никогда — только об аккредитованной школе-партнёре.
- Никаких гарантий результата, сравнений с государственной школой,
  упоминаний лицензии, маткапитала и налогового вычета.
- Цена видна на публичном сайте.
- Мультиарендность — с первого коммита, не «потом».
- Персональные данные несовершеннолетних — по 152-ФЗ в полном объёме.
- Секретов в репозитории нет, `.env` в `.gitignore`.
- `docs/2.0.xlsx` содержит фонд оплаты труда — **репозиторий приватный**.
- `async def` во вьюхах не используется вовсе: HTMX и Celery (ТЗ § 2.2).

## Грабли, на которые уже наступали

- `hx-boost="true"` на `<body>` перехватывает отправку форм — формам
  с собственным JS нужен `hx-boost="false"`.
- `hx-select="#main"` и `hx-select-oob="#site-nav"` **наследуются** всем,
  что внутри: каждой частичной подмене нужны `hx-select="unset"
  hx-select-oob="unset"`. Есть сторожевой тест в `tests/test_content_rules.py`.
- htmx на не-GET отправляет **всю окружающую форму** — список журнала
  поэтому `<div>`, а не `<form>`.
- htmx не подменяет содержимое на 4xx/5xx: отказ выглядит как мёртвая
  кнопка. Глобальный обработчик `htmx:responseError` показывает тост.
- Разметка, вставленная через `innerHTML`, htmx-ом не обрабатывается —
  нужен `window.htmx.process(el)`.
- Скрипты из `{% block cabinet_scripts %}` не приезжают при переходе
  без перезагрузки: всё для кабинета грузится в `base_cabinet.html`.
- Русская локаль печатает `33,3` — в CSS `left:` и в атрибуте `max=`
  это мусор. Есть фильтр `machine_number`, проценты считаем целыми.
- `Model._base_manager` не фильтрует мягко удалённых: обратный OneToOne
  возвращает удалённые записи (так возвращались объединённые двойники).
- В шаблоне `entry.items` у словаря попадает в метод `dict.items` —
  ключ для вложенных пунктов назван `children`.
