# Оригиналы фотографий педагогов

Сюда кладутся исходники «как есть» — из телефона, из фотосессии, неважно.
Обработку делает `scripts/prepare_teacher_photos.py`: он кадрирует под
портрет 4:5, повышает резкость, выравнивает контраст и сохраняет
оптимизированный WebP в `media/teachers/`.

## Имена файлов

Имя файла = слаг педагога из `apps/core/management/commands/setup_client_data.py`.
Расширение любое: `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic` (если установлен
`pillow-heif`).

## Как обработать

```powershell
python scripts/prepare_teacher_photos.py
python manage.py setup_client_data
```

Первая команда собирает `media/teachers/<слаг>.webp`, вторая привязывает их
к карточкам на сайте. Обе идемпотентны: можно запускать сколько угодно раз.

## Требования к исходникам

- Лицо в верхней трети кадра — скрипт кадрирует именно так.
- Минимум 800 px по короткой стороне, иначе апскейл будет заметен.
- Портретная или квадратная ориентация лучше горизонтальной.

Оригиналы коммитятся в репозиторий, чтобы деплой был воспроизводим:
`media/` в `.gitignore`, и без исходников на новом сервере фотографий не будет.
